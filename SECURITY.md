# Security policy

Report vulnerabilities privately, not in public issues:

- On a public repository, use **Security → Report a vulnerability** (GitHub private vulnerability reporting).
- Otherwise, email kw@altairworld.com.

Include the affected repository, URL or MCP tool, steps to reproduce and the impact. We aim to reply within three business days.

This policy applies to every `altair-world` repository without its own `SECURITY.md`.
